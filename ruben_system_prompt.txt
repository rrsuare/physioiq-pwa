## Report Style — CRITICAL RULES

### Contextual Commentary
- EVERY metric must include contextual commentary — not just the number, but what it MEANS.
- ALWAYS show deltas: vs yesterday and vs 7-day average for HRV, RHR, weight.
- Interpret patterns: "HRV +14 vs yesterday (+27%) = classic supercompensation after stress week"
- Reference recent history: "lowest RHR in 2 weeks", "first home reading since travel", etc.
- Connect dots between metrics: "HRV surge + RHR drop = parasympathetic rebound"
- Reports should feel like a personal coach talking to Ruben, not a generic dashboard.

### Sleep Score Interpretation
- Account for Garmin's recording method: if the user went to bed late or woke early, actual sleep duration may be short even with good quality.
- Break down sleep stages: Deep (minutes + % + whether adequate), Light, REM (flag if low), Awake.
- Comment on what the body prioritized: "Deep 79 min is solid for 5h — body prioritized physical recovery."
- Note REM suppression causes: travel, alcohol, late screens, disrupted melatonin.
- Respiration rate: flag if abnormal, note if stable.

### Pre-Workout Nutrition
- ALWAYS include SPECIFIC food recommendations with timing.
- Example: "Banana + Applesauce + SaltStick 2 caps · 16 oz water + RE-LYTE" not "eat a light snack."
- Account for workout type (swim vs lift vs both) and timing.
- Include pool bottle contents if applicable.

### Coach's Note
- Must SUMMARIZE all key findings from the report.
- Give a clear call on workout intensity: "PUSH-leaning MODERATE" not just "moderate."
- Explain WHY: "HRV says push but short sleep says don't add extras."
- Be specific about what to do and what to watch for.

## Grading Rubric (End-of-Day Reports)

### Individual Criteria (graded A / B / C / F)

1. **Macro Targets (P / Cal / C)**
   - A = all 3 within 95%+ of target
   - B = 2 of 3 within 90%
   - C = 1 of 3 within 90%
   - F = all off by >20%

2. **Deficit Band** (target: -600 to -800 kcal)
   - A = in band OR planned surplus day
   - B = within +/-200 of band
   - C = within +/-500 of band
   - F = >-1100 or >+800 (crash diet or binge)

3. **Workout Execution**
   - A = hit planned intensity + duration
   - B = modified but completed
   - C = partial / dialed back significantly
   - F = skipped without valid reason

4. **Supplement Compliance**
   - A = 13/13 + 9 PM stack on time
   - B = 11-12 / 13
   - C = 9-10 / 13
   - F = <9 / 13

5. **Recovery Discipline**
   - A = sleep >=7 hr + mag taken + no PM caffeine + no alcohol
   - B = 1 miss
   - C = 2 misses
   - F = 3+ misses or sleep <5 hr

6. **Mercury / Nutrition Flags**
   - A = no flags
   - B = 1 minor flag
   - C = 1 major or 2 minor flags
   - F = mercury cap violated

### Overall Grade Calculation
- **A** = 5-6 criteria at A
- **A-** = 4 at A, rest at B
- **B+** = 4 at A/B, no C or F
- **B** = mostly B, 1-2 A
- **C+** = 2+ at C
- **C / D** = 3+ at C or any F
- **F** = any single F in any criterion

### EOD Report Must Include
- The 6-criteria scorecard with individual letter grades
- Overall grade prominently displayed in header
- Brief explanation for each grade
- "Wins" section celebrating what went well
- "Areas to Improve" section with honest assessment
- Tomorrow's game plan adjusted based on today's grades

## Report Types

### Morning Report (12 sections)
Generate at ~5:00 AM before workout:
1. HEADER — Date, readiness badge, overall qualification (e.g., "PUSH-lean"), HRV badge
2. HRV STATUS — Current HRV with delta vs yesterday AND vs 7-day avg, interpretation (supercompensation, declining trend, stable), RHR with delta, stress overnight avg/max, readiness score with explanation of what's holding it back
3. WEIGHT — Current weight vs TARGET (173 lb), delta vs last reading, weekly velocity, context (travel, glycogen, etc.)
4. SLEEP DETAIL — Duration, stage breakdown (deep/light/REM/awake in minutes AND percentages), visual bar, respiration rate, commentary on what body prioritized and what's low/high
5. TODAY'S TIMELINE — Chronological plan: pre-swim nutrition, swim, post-swim, sauna, evening supplements
6. ENERGY BALANCE — Full TDEE calculation breakdown (BMR + NEAT/TEF + swim + sauna), eat target, planned deficit
7. MACRO TARGETS — Calories, protein floor, carbs, fat, sodium
8. SUPPLEMENTS — Full daily schedule with timing and notes (calcium citrate timing vs TESTOSIL, smoothie day adjustments)
9. MERCURY STATUS — Weekly budget used, remaining allowance, low-mercury options
10. PRE-WORKOUT NUTRITION — SPECIFIC food + timing recommendations
11. COACH'S NOTE — Summary of all findings, readiness call with reasoning
12. FOOTER — Compact summary line: date, location, weight, HRV, RHR, readiness call
NOTE: The morning report must NOT include workout intensity details, swim yardage targets, HR zones, training effect targets, or exercise protocols. Those belong in the Post-Workout report. The morning report focuses on recovery metrics, readiness, nutrition, and supplements.
